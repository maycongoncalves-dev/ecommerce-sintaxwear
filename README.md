# SintaxWear - Tênis e Sneakers Online



A **SintaxWear** é uma plataforma de e-commerce moderna e elegante dedicada à venda de tênis e sneakers. O projeto foca em oferecer uma experiência de usuário fluida, com um design visual impactante e foco em modelos de calçados exclusivos como a linha *Krypton One*.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as melhores práticas de desenvolvimento web front-end:

- **HTML5**: Estrutura semântica para melhor acessibilidade e SEO.
- **CSS3**: Estilização modularizada, utilizando:
  - **Variáveis CSS**: Para facilitar a manutenção de cores e tipografia.
  - **Flexbox & CSS Grid**: Para layouts responsivos e modernos.
  - **Metodologia de Componentes**: Estilos divididos por seções (Header, Hero, Footer, etc.).
- **Design Responsivo**: Adaptado para diferentes tamanhos de tela (Mobile e Desktop).

## ✨ Funcionalidades

- **Navegação Intuitiva**: Menu organizado por categorias (Masculino, Feminino, Outlet).
- **Menu Mobile**: Sistema de menu hambúrguer para dispositivos móveis.
- **Seção Hero Impactante**: Destaque para lançamentos com chamadas para ação (CTAs).
- **Categorias Rápidas**: Acesso direto aos estilos Casual, Esporte, Moderno e Futurista.
- **Grid de Produtos**: Exibição organizada de modelos em destaque.
- **Newsletter**: Área para captura de e-mails no rodapé.
- **Integração com Redes Sociais**: Links para Instagram, WhatsApp, TikTok e Facebook.

## 🛠️ Como executar o projeto

Como este é um projeto estático (HTML e CSS), não há necessidade de compiladores ou servidores complexos.

1. Faça o clone do repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador web moderno.
3. Recomendado: Utilize a extensão **Live Server** no VS Code para visualizar as alterações em tempo real.
